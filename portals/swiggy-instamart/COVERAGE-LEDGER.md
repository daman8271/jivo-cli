## Known gaps, stated plainly

- **Local Buying** (`/im-vendor/local-buying/*`) renders but returns no data: it resolves a `LOCAL_VENDOR` user pool to a different identity host (`influencer-app-*.swig.gy`). NOT_REACHABLE with the brand session; needs a credential JIVO may not have.
- **Brandverse** metrics returned **HTTP 403** for `ecom1@jivo.in` — the remote loads, the account is not entitled. Role-denied, not missed.
- **`searchInventoryAvailabilityMetrics`** returned **403 `Invalid Request Body`** on passive render (the page calls it before a filter is chosen), so its success shape is not captured.
- **Create/edit routes** were deliberately not opened (draft-create-on-mount risk).
- **Parameterised detail routes** need ids that this account's empty listings did not yield.
- The **ads-lane login** (`tanuj@jivo.in`) token was expired everywhere, so the ads surfaces were walked with the `ecom1@jivo.in` session instead. Everything the ads lane returned is therefore scoped to ecom1's entitlements.

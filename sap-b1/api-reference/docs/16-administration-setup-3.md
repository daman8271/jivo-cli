# SAP Business One Service Layer — Administration & Setup (part 3)

Reference for the 40 services in the `administration-setup-3` domain. Every service in this domain is a **readable ENTITY** (each exposes a `GET` collection and a `GET(id)` single-instance operation), so all support OData query with `$select` / `$filter` / `$orderby` / `$top` / `$skip`.

- **Base URL:** `https://<host>:50000/b1s/v1` (examples in the source HTML use `v2`; both are valid — `v1` shown here to match the `sapb1` CLI default).
- **Operations** are quoted exactly from `catalog/services.json`. Descriptions and field names are quoted from the API-reference HTML — never invented. Where the HTML example did not expose a field, the entry says so.
- **Tool equivalent** uses the read-only `sapb1` CLI: `sapb1 query <Entity> --select <cols> --filter "<odata>" --top <n>`.

Filter values in examples are illustrative placeholders; run `sapb1 query <Entity> --top 1` or fetch `$metadata` to confirm exact value formats (enums, dates) before relying on them.

## QueryAuthGroups
1. Purpose: Manipulate query authorization groups (used to control access to queries; GroupCode and GroupDes must be unique).
2. Type: readable ENTITY
3. Operations:
   - `GET QueryAuthGroups(id)`
   - `GET QueryAuthGroups`
   - `POST QueryAuthGroups`
   - `PATCH QueryAuthGroups(id)` — standard update
   - `PATCH QueryAuthGroups(id)` — assign group to a query category (set header `B1S-ReplaceCollectionsOnPatch: false`)
   - `PATCH QueryAuthGroups(id)` — unassign group from a query category, e.g. `CategoryId=-1` (set header `B1S-ReplaceCollectionsOnPatch: true`)
   - `DELETE QueryAuthGroups(id)` — allowed only when no query category is assigned to the group
   (The three `PATCH QueryAuthGroups(id)` entries in the catalog are the three distinct update/assign/unassign forms above.)
4. Fields (real, from HTML): `AuthGroupCode`, `AuthGroupDes`, `AuthGroupId`
   - `GET /b1s/v1/QueryAuthGroups?$select=AuthGroupCode,AuthGroupDes,AuthGroupId&$top=20`
   - `sapb1 query QueryAuthGroups --select AuthGroupCode,AuthGroupDes,AuthGroupId --top 20`

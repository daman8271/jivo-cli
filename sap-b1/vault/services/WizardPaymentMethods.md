# WizardPaymentMethods
Payment methods used by the Payment Wizard (bank, file format, amount limits) for batch payment runs. Live rows in JIVO_OIL_HANADB: 0.
## Read it
```bash
cd ~/sap-b1/cli
./sapb1 query WizardPaymentMethods --top 5
./sapb1 query WizardPaymentMethods --count
./sapb1 query WizardPaymentMethods --select "PaymentMethodCode,Description,HouseBankCode" --top 10
# outgoing-side methods only
./sapb1 query WizardPaymentMethods --filter "Type eq 'pmtOutgoing'" --top 10
```
## Key fields
| Field | Meaning |
|---|---|
| PaymentMethodCode | Method code (key) |
| Description | Method description |
| Type | Incoming / outgoing |
| PaymentMeans | Check / transfer means |
| HouseBankCountry | House bank country |
| HouseBankCode | House bank code |
| HouseBankAccount | House bank account |
| BankFileFormat | Bank-file format ID |
| MinimumAmount | Minimum run amount |
| MaximumAmount | Maximum run amount |
| CurrencyRestriction | Allowed currency restriction |
| GLInterimAccount | Interim clearing account |
## Connections

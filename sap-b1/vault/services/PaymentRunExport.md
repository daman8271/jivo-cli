# PaymentRunExport
Read-only export records produced by Payment Wizard runs for bank-file generation. Live rows in JIVO_OIL_HANADB: 0.
## Read it
```bash
cd ~/sap-b1/cli
./sapb1 query PaymentRunExport --top 5
./sapb1 query PaymentRunExport --count
./sapb1 query PaymentRunExport --select "AbsoluteEntry,RunDate,PaymentMethod,TotalAmount" --top 10
# wizard runs executed this fiscal year
./sapb1 query PaymentRunExport --filter "RunDate ge '2026-04-01'" --top 10
```
## Key fields
| Field | Meaning |
|---|---|
| AbsoluteEntry | Internal key |
| RunDate | Payment run date |
| Currency | Run currency |
| PaymentMethod | Wizard payment method |
| TotalAmount | Total paid amount |
| VendorCode | Paid vendor code |
## Connections
- Domain: [[banking-payments]]
- [[VendorPayments]] via VendorCode — payments generated by the wizard run
- [[HouseBankAccounts]] — paying house bank behind the run
- [[WizardPaymentMethods]] via PaymentMethod — the method used for the run

# DONE · DONE L

**DONE** = value achieved month-to-date against [[TGT]]; **DONE L** = the same achievement expressed as **volume in litres**. Together with TGT they yield the balance [[BAL]] (`TGT − DONE`) and the pace [[DRR]].

**Used by:** [[sales-dashboard]], [[control-panel]] · API [[sales-data]], [[targets]].
**Related:** [[TGT]], [[BAL]], [[DRR]], [[REALISE]].

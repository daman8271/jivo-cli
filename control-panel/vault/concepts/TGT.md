# TGT · DONE · DONE L

Monthly performance measures on the Sales dashboard.

- **TGT** — the monthly **target** (₹ value and/or volume) set per channel/segment/node.
- **DONE** — achieved **value** month-to-date against that target.
- **DONE L** — achieved **volume in litres** month-to-date.

`BAL = TGT − DONE` (see [[BAL]]); pace to target is tracked via [[DRR]].

**Used by:** [[sales-dashboard]], [[control-panel]] · APIs [[targets]], [[flex-targets]], [[segment-targets]], [[target-nodes]], [[channel-targets]], [[save-targets]] (write, documented only).
**Related:** [[BAL]], [[DRR]], [[REALISE]], [[channels]].

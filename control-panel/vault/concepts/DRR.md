# DRR — Daily Run Rate

**Definition.** The **per-day pace** of sales, used to project month-end and to pace against target.

**Formula.** `DRR = MTD value (or volume) ÷ working days elapsed`; projected month = `DRR × total working days`.

Feeds the "will we hit [[TGT]]?" narrative alongside [[BAL]] and [[OIH]].

**Used by:** [[sales-dashboard]], [[control-panel]] · API [[sales-data]], [[targets]].
**Related:** [[TGT]], [[DONE]], [[BAL]], [[REALISE]].

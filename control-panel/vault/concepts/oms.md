# OMS — Order Management System (B1i)

**Definition.** The automated **order-management / integration layer (SAP B1i)** that creates sales documents without human keying. In the document chain, each doc's source is flagged `oms:true` (system-created by OMS) vs a named SAP user who keyed it by hand (e.g. MANSI, SUMIT).

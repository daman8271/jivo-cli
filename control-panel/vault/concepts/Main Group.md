# Main Group

**Definition.** The SAP Business One **item Main Group** — the product-family classification (e.g. mustard oil, olive oil, blended, beverages) used to roll up sales, order-in-hand, aging and stock. A customer/party is also tagged with a governing Main Group. Sub-group provides the next drill level.

The commodity OIH variant keys it as `u_main_group` vs the standard `main_group` (see [[COMMODITY]]).

# OIH — Order In Hand

**Definition.** The **open order book**: confirmed Sales Orders that are *not yet invoiced/dispatched*. Measured in both ₹ value and volume (L). It is future revenue already committed by customers.

- **OIH RLZ** — the average realisation (₹/L) embedded in the order-in-hand (see [[BAL]]).
- Drilled by customer, main group and channel; commodity-scoped rows are separated (see [[COMMODITY]]).

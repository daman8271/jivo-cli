# Credit Note (CN)

**Definition.** A SAP **credit note** issued against a customer — money returned/adjusted. The app distinguishes **"CN for Goods"** (returns/price adjustments that reduce net sales, so they net off [[REALISE|realisation]]) from **"Claim for Services"**. Sales-vs-CN compares gross invoiced value against CNs raised.

**Used by:** [[sales-cn]], [[hidden-sales]] · API [[sales-cn]].
**Related:** [[REALISE]], [[claims]], [[compare-sales]].

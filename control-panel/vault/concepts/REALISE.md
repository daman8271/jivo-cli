# REALISE

**Definition.** *Realisation* — JIVO's core price-efficiency KPI: the **net average selling price per litre** actually earned, after schemes/discounts/credit-notes are netted off gross sales.

**Formula.** `REALISE (₹/L) = Net Sales Value (₹) ÷ Volume (L)`

The whole app is named after it: the shared JSON API lives at `/realise/api/…` and powers Control Panel, Sales and Accounts.

JIVO runs **3 branch DBs on one server**: `JIVO_OIL_HANADB` (default), `JIVO_MART_HANADB`, `JIVO_BEVERAGES_HANADB`. User `manager`/CT2025 works on all 3; `DSR` was rejected (no SL license). - **SAP 498-service Obsidian vault** built (`sap-b1/vault/`) by a 95-agent workflow — every readable entity documented, live row census across all 3 DBs, 0 broken links.
- **Grid consolidated** → everything moved into **`~/jivo-cli`** (own git). 11 CLIs + `connections/`. Compat symlinks left so old paths still work. Fixed `exim`/`jsap` `.env` discovery (was fixed-depth, broke on the move).
- **postsql added** — [[postsql]], raw Postgres (`103.89.45.76`, 16 DBs = the layer *under* the apps). Re-logged-in dead OMS/Factory tokens along the way.
- **Blinkit partner portal — studied + CLI'd** — [[blinkit-partner]]. Auto-login proven unattended. Deep study: 11 sections / 89 read endpoints → Obsidian vault (`portals/blinkit/vault/`), built by a 15-agent workflow, every endpoint cross-verified against the real SPA bundle. Then the **`blinkit-partner` read-only CLI** (65 commands) — eng-squad built (Atlas→Forge→Proof→Sentinel), live-verified (**3,553 real POs**), Sentinel-passed (zero writes wired). Fixed an `order_by`-must-be-array bug.

Diagnosed the SAP network gate: **SAP firewalls by source IP** — VPS reaches `.75`/`.76` on the same subnet but not `.192`. Fix = whitelist the VPS IP **`187.127.129.132`** on SAP's firewall (or cache SAP→postsql as fallback).
